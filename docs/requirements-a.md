# A1 功能需求分类

| 类别 | 编号 | 功能 |
| --- | --- | --- |
| **课程、资料与知识档案** | `CRS-001` | 创建课程；即使暂时没有资料也能创建 |
| | `SRC-001` | 添加文件、链接或笔记等资料 |
| | `SRC-002` | 提取资料正文，并保留原文位置和来源 |
| | `KNO-001` | 建立、修改课程的章节与知识点目录 |
| | `KNO-002` | 记录用户的知识点掌握状态，并与 AI 评估分开 |
| **考试范围与复习计划** | `EXM-001` | 设置考试日期、选择本次考点并标记重点 |
| | `PLN-001` | 根据考试范围和掌握情况生成初始复习计划 |
| | `PLN-002` | 设置不可学习时间，预览、确认或撤销计划补排 |
| | `REV-001` | 查看和执行今日任务，也可自主增加学习内容 |
| **AI 讲解与练习** | `TUT-001` | 围绕知识点或错题进行分步讲解和追问 |
| | `PRA-001` | 针对指定知识点生成练习并展示解析 |
| **试卷与答题** | `PAP-001` | 自定题量、题型和时长，创建试卷 |
| | `PAP-002` | 在线作答、自动保存、恢复进度和交卷 |
| | `IMP-001` | 导入 PDF、图片等外部试卷与答卷 |
| | `IMP-002` | 核对并修正识别出的题目、答案及对应关系 |
| | `DOC-001` | 导出可打印的 Word 试卷、答题卡和答案 |
| **批改与巩固** | `GRD-001` | 根据可靠答案批改客观题 |
| | `GRD-002` | 对主观题给出有依据的辅助评分和待复核提示 |
| | `REP-001` | 保存并查看历史批改报告及逐题分析 |
| | `ERR-001` | 记录错题、“不会做”的题及后续巩固情况 |
| **系统基础** | `SYS-001` | 备份和恢复本机数据与资料 |



## A2 核心术语
| 术语 | 它记录什么？ | 属于谁？ | 换一场考试后怎样处理？ |
| --- | --- | --- | --- |
| 知识点 | 一门课程中可单独学习、练习和评价的内容；可按章节组织，不一定是“最小”单位 | **课程** | **保留**，新考试可以再次选用 |
| 考试范围 | 本次考试选了哪些知识点，哪些是重点、哪些不考 | **某一场考试** | 旧范围保留供查阅；新考试建立自己的范围 |
| 用户自评 | 用户主动判断自己对某个知识点的掌握状态 | **用户＋知识点** | **保留**；用户随时可以调整，AI 不直接覆盖 |
| AI 评估 | 根据多次练习、错题等表现，给出该知识点的掌握建议及依据 | **用户＋知识点** | **保留并持续更新**；它与用户自评分开 |
| 复习计划 | 针对某场考试，在具体日期安排哪些学习任务 | **用户＋某一场考试** | 旧计划和完成记录保留；新考试生成自己的计划 |

已确认的日程规则：每日可学习时间按用户的全局日程记录；同一天多门课程的计划任务合计不能超过当天可用时间。全天不可学习时，该日期不能安排任何课程的新任务。

## A4 异常场景
| 场景 | 给用户的提示 | 原有数据如何保留 |
| --- | --- | --- |
| 没有资料就创建课程 | “课程已创建，可以稍后添加教材或资料。” | 保存课程名称和课程 ID；以后添加资料时关联这门课程 |
| 考试范围一个知识点也没选 | “请至少选择一个考点，再确认考试范围。” | 保留课程、知识点和范围草稿；不生成新的正式范围，也不覆盖先前已确认的范围及计划 |
| 把有任务的一天设为不可学习 | “这一天的任务受到影响，请查看调整方案。” | 保存不可学习日期；已完成任务及旧计划版本保留。受影响的未完成任务显示为待重新安排，用户确认方案后才保存新计划版本 |
