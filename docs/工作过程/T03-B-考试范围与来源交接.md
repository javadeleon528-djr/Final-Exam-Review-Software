## 仓储函数

`app.repositories.exams`：

| 函数 | 用途 |
| --- | --- |
| `create_exam(session, exam)` | 创建考试；不提交事务 |
| `get_exam(session, exam_id)` / `list_exams(session, course_id)` | 查单场考试／课程下考试 |
| `get_scope_draft(session, exam_id)` | 返回 `(draft, items)`；首次无草稿时返回 `(None, [])`，接口映射为第 0 版空草稿 |
| `save_scope_draft(session, exam_id, expected_version, items)` | 覆盖保存；`items` 是 `(point_id, included, priority_string)` 列表；版本冲突抛 `ScopeDraftVersionConflict` |
| `confirm_scope(session, exam_id, expected_draft_version)` | 返回 `(version, snapshot_items)`；拒绝空范围、跨课程知识点和旧版本号 |
| `get_confirmed_scope(session, exam_id, version_no=None)` | 返回最新或指定历史版本及条目；找不到时返回 `(None, [])` |

`app.repositories.sources`：`create_source(session, source)`、`list_sources(session, course_id)`。前者只登记 `link` 或 `note`，不抓取网页；来源 ID 由调用方生成。

`app.repositories.learning.update_self_status` 会在同一事务里写 `PointProfileEvent`。调用方提交或回滚后，状态与事件一起生效或一起撤销。

## 接口层仍须处理

- 课程不存在、考试不存在、版本冲突和内容不合法应映射成契约中的 404／409／422；仓储本身不返回 HTTP 响应。
- `ScopeDraftVersionConflict` 映射 409。正式范围确认与草稿保存的重复请求要在接口层按 `Idempotency-Key` 处理；仓储本身不保存请求键。
- API 返回范围优先级时将整数 `0/1` 转为 `normal/important`。范围草稿保存时仓储已完成反向转换。
- 数据库仓储不 `commit`；一次业务操作由服务层统一提交，异常时回滚。
