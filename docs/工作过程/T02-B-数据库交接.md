## 已接入的数据库函数

- `from app.db.connection import make_engine, check_database`
- `make_engine(database_url: str) -> Engine`：接收应用配置的 SQLite URL，创建 Engine。应用启动时创建一次并复用。
- `check_database(engine: Engine) -> bool`：执行 `SELECT 1`，可用返回 `True`，数据库连接失败返回 `False`。健康接口可据此返回 200 或 503。
- 当前开发迁移地址和应用默认地址均为 `sqlite:///./data/study.db`。旧的 `app/db/check.py` 已删除，避免再次连接 `data/app.db`。
