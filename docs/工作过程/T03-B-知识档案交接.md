## 给接口层的函数

从 `app.repositories.learning` 导入。全部接受调用方的 `Session`，只 `flush`，不 `commit`；接口服务决定事务提交和回滚。

| 函数 | 返回与用途 |
| --- | --- |
| `create_course(session, course)` | 保存并返回 `Course`；调用方构造稳定 ID |
| `get_course(session, course_id)` | `Course` 或 `None` |
| `list_courses(session)` | 未归档课程列表 |
| `create_point(session, point, user_id="local_user")` | 保存节点；`point` 节点同时创建初始档案 |
| `get_point(session, point_id)` | `KnowledgePoint` 或 `None` |
| `list_points(session, course_id)` | 该课程未归档的目录节点列表 |
| `get_profile(session, point_id, user_id="local_user")` | 当前档案或 `None` |
| `update_self_status(session, point_id, self_status, expected_version, user_id="local_user")` | 版本相符时更新自评并返回档案；不存在或版本冲突返回 `None` |

接口服务应在调用 `update_self_status` 前后区分知识点不存在（404）与版本冲突（409）；无效状态会抛 `ValueError`。创建知识点前，服务层仍需检查父节点归属、类型、归档状态和循环关系。
