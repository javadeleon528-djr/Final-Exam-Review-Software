> 标记：【已确认】来自设计文档的决定；【待确认】团队尚未决定，当前值为建议值。

## 使用规则

1. **一个概念只有一个词。** 中文用于 UI，英文键名用于代码，两者一一对应，不设同义词。
2. **定义写边界，不写功能。** 每条必须写清"不是什么"，因为混淆几乎都发生在相近概念之间。
3. **英文键名即代码。** 表名、字段名、枚举值直接用本文的写法，不另创缩写。
4. **枚举以本文为准，且必须与 `api-contract.yaml` 的 enum 同步。** 两处不一致视为契约缺陷，不是"以文档为准"或"以代码为准"。
5. **不可变的东西要写进定义。** 凡标注"版本""快照"的对象，一旦写入不得原地修改，否则这条术语没有意义。

## 一、核心对象

| 中文 | 英文键名 | 定义 | 不是什么 | 需求 |
| --- | --- | --- | --- | --- |
| 课程 | `course` | 一门课的学习容器，可只填课程名创建，后续逐步挂载资料 | 不是"学期"或"考试"；一门课可有多场考试 | CRS-001 |
| 资料 | `source` | 用户上传的文件、粘贴的正文或提供的链接，含原件路径与元数据 | 不是"正文"；资料可以没有可用正文（如受限网页） | SRC-001 |
| 正文片段 | `source_segment` | 从资料中切出的、带页码或链接定位的可引用文本单元 | 不是资料的全文副本；切分后仍须能回到原件位置 | SRC-002 |
| 知识点 | `knowledge_point` | 课程内的稳定目录节点，拥有不可复用的 ID，供范围、题目、错题共同引用 | 不是"章节"（章节只是它的层级表现）；不是自评状态的载体 | KNO-001 |
| 用户自评 | `self_status` | 用户自己给出的知识点掌握状态，只能由用户修改 | 不是"掌握率"，不做百分比，不由练习结果自动改写 | KNO-002 |
| AI 建议 | `ai_status` | AI 依据练习表现推断的掌握建议，与自评分列存储 | **不得覆盖**自评；仅作参考呈现 | KNO-002 |
| 考试 | `exam` | 一次具体的考试事件，含日期与每日可用分钟 | 不是"课程"；同一课程可有多场考试，各自有独立的范围与计划 | EXM-001 |
| 范围草稿 | `scope_draft` | 用户正在勾选的考点集合，可反复修改 | 不是正式范围；不可被报告或计划引用 | EXM-001 |
| 范围版本 | `scope_version` | 用户确认后生成的**不可变**考点快照，带递增版本号 | 不是"当前勾选状态"；确认后加新考点必须产生新版本 | EXM-001 |
| 范围条目 | `scope_item` | 范围版本中的一个知识点及其是否纳入、普通/重点 | 不是知识点本身；范围外不代表知识点被删除 | EXM-001 |
| 可用日 | `availability_day` | 某本地日期可学习的分钟数，0 表示全天不可学 | 不是"任务时长"；它是容量上限，不是安排结果 | PLN-002 |
| 计划版本 | `plan_version` | 一次正式应用后的排程快照，可撤销回到上一版 | 不是"待预览的方案"；预览不能直接当正式计划 | PLN-001 |
| 补排预览 | `plan_preview` | 标注不可学日后算出的候选方案，含移动、不动与排不进的差异 | 不是正式计划；取消预览只删草稿，不动原任务 | PLN-002 |
| 计划任务 | `plan_task` | 计划版本中一条可执行的学习安排（日期、时长、状态、是否锁定） | 不是"知识点"；一个知识点可拆成多个任务 | PLN-001 |
| 试卷版本 | `paper_version` | 出题后固定的题目快照，题号与分值不再变动 | 不是"试卷模板"；旧作答永远指向它生成时的版本 | PAP-001 |
| 题目 | `paper_item` | 试卷版本中的一道题，含题号、题干、答案与评分点 | 不是"练习题"（通用概念）；必须有稳定题号 | PAP-001 |
| 作答批次 | `attempt` | 用户对某个试卷版本的一次完整作答，含草稿、提交与快照 | 不是"试卷"；同一份卷可有多批次，各自独立计分 | PAP-002 |
| 作答记录 | `attempt_answer` | 批次中单题的答案、草稿、标记与版本号 | 不是"标准答案"；交卷后不可再改 | PAP-002 |
| 导入任务 | `grading_import` | 外部试卷/答卷文件的上传与识别任务 | 不是"资料"；虽然共用文件存储，但业务目的不同 | IMP-001 |
| 识别版本 | `recognition_version` | 对导入件的一次识别结果，含机器候选与用户确认版 | 不是"原件"；原始 OCR 结果不可被修订覆盖 | IMP-002 |
| 批改运行 | `grading_run` | 一次评分过程，固定引用答案依据、模型与提示词版本 | 不是"成绩"；同一批次可有多次运行，旧运行不改写 | GRD-001 |
| 批改条目 | `grading_item` | 批改运行中单题的得分、证据、置信与复核状态 | 不是"最终分数"；待复核项不进入确定总分 | GRD-002 |
| 报告 | `report` | 某次批改运行的汇总视图，含逐题分析与弱点 | 不是"实时统计"；它是快照，不随范围版本变化而改写 | REP-001 |
| 错题 | `mistake` | 关联到作答批次与知识点的待巩固条目，区分"做错"与"不会做" | 不是"错题本页面"；同题不同批次可各成一条 | ERR-001 |
| 异步任务 | `job` | 长耗时操作的状态记录，浏览器关闭后仍存在 | 不是 HTTP 请求；不要用一次请求挂起等待结果 | 全部异步 |

## 二、枚举

### job.status【已确认】

`queued` → `running` → `needs_review` / `done` / `failed` / `cancelled`

- `needs_review` 表示**需要人工核对**，不得自动重试至覆盖用户修订
- `failed` 必须携带可读错误码与重试入口，不显示百分比进度

### grading_item.result【已确认】

| 值 | 含义 | 是否计入确定总分 |
| --- | --- | --- |
| `scored` | 标准答案与证据充分，给出确定分 | 计入 |
| `reference_only` | 无可靠标准，仅给参考评分 | **不计入**，单列 |
| `needs_review` | 无法可靠判断 | **不计入**，不得算 0 分也不得算满分 |

### self_status【待确认：四态命名未定】

设计文档只写了"自评四态"，未给出具体值。建议：

`not_started`（未开始）/ `heard`（听过但不熟）/ `practiced`（做过题）/ `can_explain`（能讲清）

理由：四态应描述**学习深度递进**，而不是"对/错"。若采用其他分档，需同步改 `api-contract.yaml` 与前端选择器。

### priority【已确认】

`normal`（普通考点）/ `key`（重点）

### plan.strategy【已确认】

`even`（均匀分摊）/ `key_first`（保障重点）/ `keep_original`（尽量不动原计划）

### plan_task.status【待确认：建议值】

`todo` / `done` / `skipped`；`locked` 是独立布尔字段，不是状态值

### 错误码【已确认】

`VALIDATION_ERROR`、`VERSION_CONFLICT`、`SOURCE_UNAVAILABLE`、`OCR_LOW_CONFIDENCE`、`ANSWER_KEY_MISSING`、`GRADING_NEEDS_REVIEW`、`AI_TIMEOUT`、`PLAN_INFEASIBLE`、`STORAGE_ERROR`

## 三、禁用词对照

| 不要用 | 用这个 | 原因 |
| --- | --- | --- |
| 课程进度 / 复习进度 | `scope_version` 或具体任务完成数 | "进度"是多义词，指范围还是排程说不清 |
| 掌握率 / 掌握百分比 | `self_status` | 四态自评不是连续量，百分比是假精度 |
| 一次测试 / 一套卷 | `attempt` | 卷是 `paper_version`，作答是 `attempt`，混用会导致重考覆盖历史 |
| 批改结果 | `grading_run` + `grading_item` | "结果"不区分一次运行与逐题得分，无法追溯 |
| 当前计划 | `plan_version`（带版本号） | 不说版本就无法实现撤销与冲突检测 |
| 任务完成率 | `plan_task` 状态统计（注明仅统计必做） | 额外学习不计入，否则完成率失真 |

## 四、字段命名约定

- 时间：`created_at` / `updated_at` / `confirmed_at` / `applied_at`，存 UTC，前端按本地日期展示
- 版本：`version_no`（人读递增号）与 `expected_version`（乐观锁入参）区分开，不要共用一个字段
- 幂等：写操作携带 `idempotency_key`，同一键只产生一条记录
- 相对路径：文件字段统一存相对路径 + `sha256`，不存绝对路径
- 日期：`local_date` 表示用户本地日历日，`exam_at` 表示带时区的时间点，两者不混用
